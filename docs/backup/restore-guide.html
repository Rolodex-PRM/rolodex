Backup & recovery

Restore guide

Restore replaces the live database and uploads with the contents of a backup directory. It never silently merges into an existing installation.

Before you start

  • Have a backup directory created by scripts/backup.sh (with manifest and checksums).
  • Run ./scripts/verify-backup.sh path/to/backup first when possible.
  • Put the original CREDENTIALS_KEY (and matching POSTGRES_* if you keep the same .env) on the target machine.
  • Expect existing data to be overwritten. Take a fresh backup of the current install if you might need it.

Restore steps

Compose must already be up so Postgres and volumes exist:

docker compose up -d
./scripts/verify-backup.sh backups/2026-11-20_093000
./scripts/restore.sh backups/2026-11-20_093000 --confirm

The --confirm flag is required. Without it the script exits and does not change data.

PowerShell (via bash):

bash ./scripts/restore.sh backups/2026-11-20_093000 --confirm

What the script does

  1. Preflight — required files, checksums, manifest format, archive path safety, dump readability, Postgres major version check.
  2. Stop — stops the rolodex service so nothing writes during replace.
  3. Database — pg_restore --clean --if-exists into the Compose database.
  4. Uploads — clears the uploads volume and extracts uploads.tar.gz.
  5. Start — starts rolodex again.

If a stage fails, the script exits nonzero and names the stage. Do not treat a partial restore as a healthy install — see troubleshooting.

After restore

  • Open the site and sign in with an existing administrator account.
  • Open a person who had an attachment and confirm the file loads.
  • If Immich, mailbox, or other integrations error on secrets, confirm CREDENTIALS_KEY.
  • Update PUBLIC_URL / reverse proxy if the hostname changed (migration).

If restore fails mid-way

The database and uploads are separate stages. A failure after the database step may leave uploads from the previous install. Re-run restore from a known-good backup after fixing the error, or recreate volumes and restore into a fresh Compose project. Details: Recovery troubleshooting.
