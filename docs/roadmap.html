Roadmap

Planned milestones toward 1.0. Dates are not promised; order reflects what should harden next for self-hosters. Current docs target .

  1. v0.3.0

    Multi-arch support shipped

    Publish and verify Docker images for common CPU architectures so ARM hosts (including many NAS and cloud instances) pull the same tags as amd64.

  2. v0.4.0

    Backup and restore support shipped

    Complete portable backups (Postgres + uploads), verification, restore/migration guides, Admin → Backups with schedule and retention, and CI round-trip testing. See the backup, restore, and migration guides.

  3. v0.5.0

    Finalizing the contact page

    Finish the person record as the daily workspace: layout, fields, history, and the actions people use every day.

  4. v0.6.0

    More robust relationships

    Strengthen named ties, households, and the network map so relationships stay accurate as the book grows.

  5. v0.7.0

    Mobile support and UX

    Focus on phone and small-screen use of the web app, plus the friction that shows up when sync clients and the site disagree.

  6. v0.8.0

    Docs, support help, and Discord

    Expand install and operations docs, add clearer help for common failures, and open a Discord for community support.

  7. v0.9.0

    Long-term name and branding

    Confirm the product name, mark, and visual language for the long haul before calling the project stable.

  8. v1.0.0

    Full release

    Public 1.0: marketing push, clearer upgrade promises, and much more care about breaking changes.

Ideas and bug reports still belong in GitHub Discussions and issues. This roadmap is a guide for maintainers, not a contract.
